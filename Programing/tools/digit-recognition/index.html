HOW IT WORKS

从手写数字到识别结果

点击“开始识别”后，网页会按下面 5 个步骤处理你写下的数字。整个过程都在当前浏览器中完成，不会上传图片。

01

读取手写笔迹

画板会记录你用鼠标或手指画出的白色线条，并把整块画板读取成一张图片。

可以理解为：先给画板拍一张照片。
02

找到数字并居中

程序找出所有白色笔迹的范围，去掉四周多余的黑色区域，再按比例缩放并放到正中央。

这样无论数字写在画板哪里，模型看到的位置都比较统一。
03

转换为 28×28 图像

处理后的数字会缩小成 28×28 像素的灰度图，每个像素都会转换成 0 到 1 之间的数值。

这是 MNIST 模型训练时使用的标准输入格式。
04

交给本地模型判断

ONNX Runtime Web 把这些像素数值送入已经训练好的 mnist-8.onnx 模型，由模型比较它与 0～9 的特征。

推理只在你的电脑中进行，不需要后端服务器。
05

显示数字和概率

模型会为 0～9 分别给出一个分数。网页将分数转换成百分比，并把最高的一项作为预测结果。
