# ML Learn｜机器学习互动教学网站

## ⚠️ 运行前请先阅读

### 必须使用 Live Server 打开网站

本项目不能直接双击 HTML 文件运行，请使用 VS Code 的 **Live Server** 扩展启动。

如果直接通过 `file://` 打开网页，可能导致以下功能失效：

- 页面数据和部分 JavaScript 文件无法正常加载；
- 手写数字识别模型无法加载；
- ONNX、WASM 等模型资源运行失败；
- 页面跳转、实验记录或其他互动功能出现异常。

### 推荐启动方法

1. 使用 VS Code 打开本项目最外层文件夹。
2. 找到最外层的 `index.html`。
3. 右键单击 `index.html`。
4. 选择 **Open with Live Server**。
5. 浏览器打开本地网址后即可开始体验。

推荐使用最新版 Chrome 或 Edge 浏览器，并保持项目文件夹结构完整。

## 项目介绍

ML Learn 是一个面向机器学习初学者的互动教学网站。

网站不仅提供机器学习基础知识和经典算法介绍，还加入了知识树、答题任务、算法可视化实验、手写数字识别和学习记录等功能，帮助学习者通过实际操作理解机器学习。

网站主要包含：

- 机器学习发展历史；
- 机器学习基础知识；
- 经典算法介绍；
- 互动练习；
- 手写数字识别；
- KNN 鸢尾花分类实验；
- 鸟类决策树实验；
- K-Means 聚类实验；
- 学习情况与实验记录；
- 项目成员介绍。

## Iris 互动助手

Iris 是网站中的机器人学习助手。部分 Iris 互动并没有使用非常明显的按钮，请留意页面中的机器人图像。

### 欢迎页

点击欢迎页中央的 Iris，可以进入网站的登录与注册引导。

### 首页自我介绍

首页中的 Iris 介绍卡片可以连续点击。卡片中包含三段介绍文字，每次点击会进入下一段。

Iris 还会根据鼠标位置产生轻微的移动和转向效果。

### 页眉中的 Iris

部分页面右上方的 Iris 不只是装饰。点击它可以帮助用户向下浏览页面内容。

### 音乐控制

页眉附近的音乐图标可以：

- 播放或暂停背景音乐；
- 调整音量；
- 保存当前浏览器中的音乐开关和音量设置。

由于浏览器的自动播放限制，首次打开页面时可能需要先点击页面，背景音乐才能开始播放。

## 不容易被注意到的互动功能

### 1. 基础知识树

进入“课程 → 基础知识”后，可以看到一棵完整的机器学习知识树。

知识树包含：

- 13 个知识章节；
- 80 个知识点；
- 章节快捷切换；
- 独立章节详情页面。

可以点击章节枝条、顶部章节按钮或叶片编号，查看相应知识点并进入章节正文。

---

### 2. 互动练习与救援任务

互动练习包含：

- 判断题；
- 选择题；
- 填空题；
- 配对题。

进入练习前，可以选择知识章节和出题顺序。出题顺序支持章节顺序和随机顺序。

每次正确作答都会修复一个知识节点。完成全部题目且正确率达到 70%，即视为救援成功。

配对题除了支持拖动卡片，还支持“先点击卡片，再点击目标位置”的操作方式，方便触屏设备使用。

练习结果会保存在当前浏览器中，并显示在互动练习首页和学习情况页面。

---

### 3. 手写数字识别

进入“可视化实验 → 手写数字识别”，可以在黑色画板中写下一个 0～9 的数字。

点击“开始识别”后，网页会：

1. 读取手写笔迹；
2. 找到数字所在区域；
3. 将数字居中并转换为 28×28 图像；
4. 使用本地 MNIST 模型进行推理；
5. 显示预测数字和 0～9 的完整概率分布。

识别过程使用 ONNX Runtime Web 在浏览器本地完成，不会上传手写图片。

建议将数字写在画板中央，并尽量写得清晰。

---

### 4. KNN 鸢尾花分类实验

KNN 实验使用真实 Iris 鸢尾花数据集。

可以调整：

- 花萼长度；
- 花萼宽度；
- 花瓣长度；
- 花瓣宽度；
- K 值。

页面会实时显示：

- 预测的鸢尾花品种；
- 预测置信度；
- K 个最近邻居；
- 三个品种的投票数量；
- 待测样本与邻居的特征位置。

点击“存档本次操作”后，网页会保存当前参数、预测结果和最近邻信息。保存的记录可以从实验页面或“学习情况”页面查看。

这些记录只保存在当前浏览器中。

---

### 5. 鸟类决策树实验

决策树实验包含多种操作方式，其中部分功能需要主动尝试才能发现。

#### 调整问题顺序

页面顶部的四张问题卡可以拖动排序。不同的问题顺序会生成不同的筛选路径和决策树。

四个问题包括：

- 能否飞行；
- 是否产卵；
- 是否有翅膀；
- 是否有羽毛。

#### 自动筛选

点击“请 Iris 开始筛选”，Iris 会按照当前问题逐层移动和分类动物卡片。

筛选过程中可以点击“跳过动画”，直接查看当前层的分类结果。

#### 手动分类与 Iris 纠正

除了让 Iris 自动筛选，还可以手动操作：

1. 点击动物卡片，或者直接拖动动物卡片；
2. 将动物放入右侧的“是”或“否”分支；
3. 如果分类位置错误，Iris 会给出提示；
4. Iris 会将放错的卡片送回正确分支，帮助用户修改分类。

这项“帮助纠正”功能只有在手动放错动物卡片时才会触发。

#### 快速进入结果分析

如果不想等待完整的四层动画，可以点击“快速进入结果分析”。

结果分析会保留当前设置的问题顺序，并展示每一层的真实筛选结果。

#### 点击分析页面中的 Iris

进入结果分析后，除了点击“继续”按钮，也可以直接点击讲解卡片中的 Iris 进入下一步。

分析内容包括：

- 为什么鸵鸟会暴露规则漏洞；
- 手动规则与真正的决策树训练有什么区别；
- 基尼系数；
- 信息熵；
- 决策树的常见应用；
- 决策树的优点与局限。

#### 神秘动物挑战

完成结果分析后，会解锁“神秘动物”。

点击神秘动物后会出现企鹅，并比较两棵决策树的判断路径：

- 原始规则可能因为企鹅不会飞而将它错误排除；
- 修改后的规则会使用“是否有羽毛”等更合适的特征正确识别企鹅。

训练数据中的鸵鸟用于发现规则漏洞，企鹅则用于检验决策树面对新样本时的泛化能力。

### 6. K-Means 聚类实验

K-Means 实验支持两种添加数据的方式：

- 在画布上点击，手动添加数据点；
- 点击“随机生成”，快速创建示例数据。

设置 K 值后，可以选择：

- “自动运行”：连续完成聚类；
- “单步执行”：逐步观察样本分配和质心更新。

页面还会显示迭代次数、质心位置和 SSE 变化，便于观察算法逐渐收敛的过程。

---

### 7. 机器学习历史时间轴

“了解历史”页面中的年份节点可以点击。

选择不同年份后，右侧内容会切换为对应的机器学习事件、背景、代表人物和影响，并且当前年份会写入页面网址，方便定位具体历史节点。

## 本地数据说明

本项目没有连接远程数据库。

以下数据主要保存在当前浏览器中：

- 注册账号和登录状态；
- 互动练习完成记录；
- 答题正确率；
- 救援成功次数；
- KNN 实验存档；
- 音乐开关和音量设置。

更换浏览器、清除浏览器数据或使用其他电脑后，原有记录不会自动同步。

如果需要从全新状态体验网站，可以清除该网站的本地存储，或者使用浏览器无痕窗口重新打开。

## 使用建议

建议按照以下顺序体验：

1. 从欢迎页进入网站；
2. 注册或登录账号；
3. 查看机器学习历史；
4. 进入基础知识树；
5. 阅读经典算法；
6. 完成互动练习；
7. 体验四个可视化实验；
8. 在“学习情况”中查看练习与实验记录；
9. 查看项目成员介绍。
