01

回归算法

回归模型用于预测连续数值，例如房价、销量、温度、等待时间或风险金额。

线性回归

假设目标可以由特征的加权组合近似，通常通过最小化均方误差或最大似然估计参数。它训练速度快、系数含义清楚，适合建立第一个基线。

适用场景：特征与目标近似线性、需要解释每个特征方向和影响大小的任务。

局限性：对非线性关系、异常值和特征共线性敏感，需要检查残差并配合正则化。

多项式与正则化回归

通过交互项、多项式项或样条基函数表达曲线关系，再用 L1、L2 或弹性网络限制模型复杂度。

适用场景：样本量中等、希望保留线性模型可解释性但又需要表达温和非线性的任务。

局限性：阶数过高会导致特征数量爆炸和过拟合，必须通过验证集选择复杂度。

02

分类算法

分类模型输出离散类别或类别概率，阈值应结合误报、漏报和实际资源约束选择。

逻辑回归

把线性得分通过 sigmoid 函数映射为 0 到 1 的概率，并以交叉熵或负对数似然训练。

适用场景：二分类、稀疏特征、需要稳定概率和较强解释性的任务。

局限性：决策边界本质上线性，复杂交互需要人工构造特征或换用非线性模型。

KNN 最近邻

预测时查找距离最近的 K 个训练样本，分类进行投票，回归进行加权平均。

适用场景：数据规模较小、局部相似性有意义且距离度量可靠的任务。

局限性：推理成本随样本量增加，严重依赖特征尺度和距离度量，维度过高时会出现维度灾难。

朴素贝叶斯

基于给定类别后特征条件独立的假设，使用贝叶斯公式计算类别后验概率。

适用场景：文本分类等高维稀疏数据，或需要快速建立概率基线的任务。

局限性：独立性假设较强，概率往往需要校准，特征之间的复杂关系难以表达。

03

决策树、随机森林与梯度提升

树模型可以通过一系列条件切分特征空间，天然表达非线性和特征交互，是结构化数据的常用方法。

决策树

每次选择一个特征和切分点，让子节点尽可能纯。分类常用基尼系数或信息增益，回归常用方差减少。

适用场景：需要规则表达、特征类型混合、关系明显非线性的教学和业务任务。

局限性：深树方差较大，对训练样本的小变化敏感，必须限制树深或使用剪枝。

随机森林

对样本进行 Bootstrap 抽样并训练多棵树，同时在每次分裂时随机选择特征子集，再通过投票或平均降低方差。

适用场景：中小规模表格数据、特征关系复杂且需要较稳健基线的任务。

局限性：模型体积可能较大，概率校准和外推能力有限，原生特征重要性可能偏向取值较多的特征。

梯度提升树

按顺序训练弱学习器，每一步拟合前面模型的残差或损失负梯度。XGBoost、LightGBM 和 CatBoost 都属于常用实现。

适用场景：结构化数据、非线性关系明显、对预测精度要求较高的任务。

局限性：对学习率、树数、深度和采样策略敏感，训练与验证过程必须严格防止数据泄露。

04

聚类与降维

无监督算法不依赖人工标签，而是尝试发现样本之间的相似结构、密度差异或低维表示。

K-Means

反复执行“分配样本—更新中心”，最小化簇内平方距离。肘部法则、轮廓系数和 Gap 统计量可以辅助选择簇数。

适用场景：簇大致呈球状、规模相近，且可以使用均值代表一组样本的任务。

局限性：需要预先指定 K，对初始化敏感，无法自然表达细长或密度差异很大的簇。

DBSCAN 与层次聚类

DBSCAN 依据密度发现任意形状的簇并标记噪声；层次聚类通过逐步合并或拆分形成树状图，可以选择不同粒度。

适用场景：需要识别噪声、簇形状不规则，或希望从树状结构观察多个分组层次。

局限性：DBSCAN 对半径和最小样本数敏感，层次聚类在大规模数据上的计算成本较高。

PCA、t-SNE 与 UMAP

PCA 保留方差较大的线性方向，t-SNE 和 UMAP 更强调局部邻域，常用于压缩或二维可视化。

适用场景：可视化高维数据、去除共线性、压缩输入或探索潜在结构。

局限性：可视化中的距离和簇间空隙不能过度解释，结果受尺度、随机种子和超参数影响。

05

神经网络与深度学习

神经网络通过多层线性变换和非线性激活函数学习层次化表示，适合图像、文本、语音和复杂多模态数据。

基础结构

神经元先计算加权和，再通过 ReLU、sigmoid 或 tanh 等激活函数引入非线性。前向传播得到预测，反向传播依据链式法则计算梯度。

适用场景：样本量较大、输入结构复杂、需要从原始数据自动学习表示的任务。

局限性：训练成本、数据需求和调参复杂度较高，结果通常比线性模型和浅层树模型更难解释。

CNN、RNN 与 Transformer

CNN 用局部感受野和权重共享处理图像网格；RNN、LSTM 和 GRU 通过隐藏状态处理序列；Transformer 以注意力机制捕捉长程依赖并支持并行训练。

适用场景：图像、语音频谱、文本、时间序列和需要迁移学习的大规模任务。

局限性：需要谨慎处理过拟合、梯度消失、计算资源、概率过度自信和生成内容的安全风险。

06

支持向量机与异常检测

这两类方法分别解决最大间隔分类和少数异常样本识别问题，适合中小规模、边界清晰或异常样本稀缺的数据。

支持向量机（SVM）

SVM 寻找能够最大化类别间隔的分隔超平面，真正决定边界的是距离超平面最近的支持向量。软间隔参数 C 用于平衡间隔宽度和训练误差，核函数则把线性方法扩展到非线性边界。

训练与选择：先标准化特征，再通过交叉验证联合选择 C、核函数和核参数；线性核适合高维稀疏特征，RBF 核适合样本量中等的非线性关系。

局限性：核 SVM 在大样本上的时间和内存成本较高，概率输出需要额外校准，参数不当时容易欠拟合或过拟合。

孤立森林、单类 SVM 与局部离群因子

孤立森林利用异常点更容易被随机切分隔离的特点计算异常分数；单类 SVM 学习正常数据的边界；局部离群因子比较样本与邻域的局部密度。

适用场景：欺诈检测、设备故障、网络攻击和数据质量监控。阈值应结合人工核验能力与误报成本，而不是只看无监督分数。

局限性：异常通常缺少稳定标签且会随时间变化，离线评估需要构造可信验证集，上线后还要持续监控分布漂移。

07

迁移学习与生成模型

当标注数据不足或任务需要生成新内容时，可以复用预训练表示，或直接学习数据分布并从中采样。

迁移学习与微调

迁移学习先使用大规模通用数据训练基础模型，再将已学到的表示迁移到目标任务。实践中可先冻结骨干网络只训练任务头，再逐步解冻并使用更小学习率微调。

适用场景：图像分类、文本理解、语音识别以及目标领域标注样本有限的任务。

局限性：源域与目标域差异过大会产生负迁移；微调还可能导致灾难性遗忘，需要分层学习率、早停和独立验证集。

VAE、GAN 与扩散模型

VAE 通过概率潜变量学习连续表示；GAN 让生成器与判别器对抗训练；扩散模型通过逐步加噪和学习反向去噪过程生成高质量样本。

适用场景：图像与文本生成、数据增强、缺失信息补全、表征学习和创意辅助。

局限性：生成质量不能只靠视觉判断，还应检查多样性、真实性、偏见、隐私泄露和版权风险，并对输出建立安全审查机制。

08

算法对比与选择建议

算法没有脱离数据和目标的绝对优劣，选择时应先建立简单基线，再根据误差分析决定是否增加复杂度。

算法 任务类型 适用场景 主要优势 主要局限性
线性回归 回归 近似线性且需要解释 快速、稳定、系数清晰 难表达复杂非线性
逻辑回归 分类 二分类、稀疏特征 可输出概率、易解释 边界偏线性
KNN 分类 / 回归 小规模、局部相似 直观、训练简单 推理慢、怕高维
决策树 分类 / 回归 规则和交互明显 表达非线性、易讲解 容易过拟合
随机森林 分类 / 回归 稳健的表格基线 降低方差、对预处理要求较低 模型较大、外推有限
梯度提升树 分类 / 回归 结构化数据精度优先 通常具有很强的预测能力 调参与防泄露要求高
K-Means 聚类 球状、规模相近的簇 速度快、易实现 需要指定簇数
神经网络 分类 / 回归 / 生成 大规模复杂数据 自动学习高阶表示 训练和解释成本较高

实践中可以按“业务目标 → 数据切分 → 可解释基线 → 误差分析 → 复杂模型 → 上线监控”的顺序推进。只有当复杂模型在正确验证协议下带来稳定收益，并且收益足以覆盖维护成本时，才值得投入更高的系统复杂度。
