# 网站初始框架模仿制作指引

建议先照着做出页面，再逐块修改并观察变化，不需要一次记住所有代码。

## 1. 认识项目文件

```text
小学期项目/
├─ index.html       网页的内容与结构
├─ style.css        网页的外观与排版
└─ images/          后续存放图片
```

可以把 HTML 想成房屋结构，把 CSS 想成装修。

## 2. 建立 HTML 骨架

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>机器学习网站</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>网页内容写在这里</body>
</html>
```

`link` 用来连接 CSS 文件，没有这一行，CSS 不会生效。

## 3. 划分页面区域

```html
<header>页眉</header>
<main>主要内容</main>
<footer>页底</footer>
```

页眉通常放网站名称、导航、登录和注册；`main` 放课程内容；页底放辅助链接和版权信息。

用 `<section>` 划分主内容中的模块。`id="courses"` 可以和 `href="#courses"` 配合，点击导航后滚动到课程区域。

## 4. 用 CSS 变量管理颜色

```css
:root {
    --purple-600: #6d4bd1;
    --purple-50: #f7f5ff;
    --text-main: #242033;
    --white: #ffffff;
}

body {
    color: var(--text-main);
    background: var(--white);
}
```

以后想更换全站主色，只修改变量即可。

## 5. 用 Flexbox 排列页眉

```css
.header-inner {
    display: flex;
    align-items: center;
    justify-content: space-between;
}
```

- `display: flex` 开启弹性布局。
- `align-items: center` 让元素垂直居中。
- `justify-content: space-between` 让元素分布在两端。

## 6. 用 Grid 排列卡片

```css
.card-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 22px;
}
```

这表示建立三个等宽列，`gap` 是卡片间距。

## 7. 制作按钮

```css
.button {
    display: inline-block;
    padding: 10px 20px;
    border: 1px solid #6d4bd1;
    border-radius: 8px;
}

.button-primary {
    color: white;
    background: #6d4bd1;
}
```

登录和注册目前只有入口外观。真实账户功能还需要表单、JavaScript、服务器程序和数据库。

## 8. 适配手机

```css
@media (max-width: 820px) {
    .card-grid {
        grid-template-columns: 1fr;
    }
}
```

屏幕不超过 820 像素时，三列卡片会变成一列。

## 9. 运行网页

可以直接双击 `index.html`。也可以在 VS Code 中安装 Live Server，右键 `index.html`，选择 **Open with Live Server**。

## 10. 推荐练习

1. 修改 `--purple-600`，观察全站主色变化。
2. 修改 `.hero` 的 `padding`，观察欢迎区域高度变化。
3. 将 `.card-grid` 的三列改为两列。
4. 修改按钮的 `border-radius`，比较圆角效果。
5. 把占位文案逐步换成真实课程内容。

当前版本尚未实现真实登录、课程详情、KNN 互动演示和数据库，这些适合后续逐步加入。
